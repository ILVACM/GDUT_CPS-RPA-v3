## 三、程序怎么跑（通俗版）

1. **入口**：`rpa_engine/main.py` → `gui.app.launch_gui()`。启动先做 6 项自检（Python 版本、依赖、目录可写、操作目录注册、注册表字段自洽、上次配置载入），失败弹人话弹窗并退出。**无 CLI**（2026-09-13 W-18 已移除）。
2. **四阶段 GUI 闭环**：输入数据选择 → 操作配置（左 DAG 只读画布 + 右参数面板）→ 运行追踪 → 结果报告 → 回到阶段 1。
3. **执行链**：`gui/worker.py`（QThread，线程内自建连接）→ `engine/executor.execute_workflow()`：
   - 引用链校验 → 兜底补导（缺失输入表按 `tables[].source` 重新导入，且受导入白名单约束）
   - 步骤循环 → `ops/step_executor.execute_step()` 单步翻译与分发（表号→物理表名、参数白名单过滤、输出表命名 `t_s{n}` / GUI 链路 `t_{uid}`）
   - `on_error` 三档（stop/skip/retry）＋ 步骤间取消检查点 ＋ 超时告警（默认 600s）
   - finally 清理中间表/连接；`keep_db` 可保留
4. **数据底座**：全流程 SQLite 单连接（WAL + synchronous=NORMAL）作为步骤间唯一载体，**禁止传 DataFrame**；Pandas 只做复杂精加工。
5. **业务逻辑唯一载体**：JSON 参数文件（`__meta.schema_version="3.1"` + `tables[]` + `steps[]`）；旧 v3 格式明确拒绝。
6. **用户操作目录（9 项）**：`filter` / `dedup` / `mapping_match` / `aggregate` / `export` / `merge_tables` / `copy_table` / `rename_columns` / `convert_dtype`。每项 8 字段（`func`/`description`/`output`/`param_keys`/`params_schema`/`extra_input_min`/`overwritable`/`deprecated`），`params_schema` 是**参数契约唯一源**（GUI `default_params()` 与引擎缺省回退都从它派生——R15 核心成果）。
7. **扩展方式（红线）**：新增操作只在 `ops/` 实现 + 登记 `BUILTIN_OPS`，不改 `engine/` 编排代码；新增功能函数要按 `docs/function-spec-rules.md` §5.5 的 13 项 canonical 清单三形态同步（后端/JSON/前端），GUI 形态未经用户说明必须**硬停止**。
