## 界面功能

| 功能 | 说明 |
|------|------|
| 全览 | 一键缩放至全图 |
| 模拟运行 | 按执行序推进状态（S2 将定格在"失败"演示失败态） |
| ＋条件筛选 / ＋跨表映射匹配 / ＋条件统计 / ＋数据表复制 | **添加步骤**（注册表驱动）：按当前选中项插入——无选中=流程末尾（末步导出则插其前）；选中步骤=其后；选中表=其产出步骤/最后消费者之后 |
| 更多功能 ▾ | 下拉添加其余功能（条件去重/数据表合并/表头名称修改/数据类型转换/结果导出） |

画布交互（**只读**）：**Ctrl+滚轮**缩放（0.4~2.5 倍）；**空白处拖拽**平移；**点击节点**右侧看详情与配置。画布不做任何拖拽/连线编辑——配置全部在右侧面板完成。

## 右侧配置面板（动态配置唯一入口）

- **选中步骤**：参数表单（目标表/附加输入表/操作参数，按功能注册表动态生成）+「保存参数」+「删除此步骤」（二次确认）。保存后 DAG 全量联动刷新（表节点/连线/顶部表区/开始结束标识）。
- **选中表**：表信息 +「弃用此表 / 恢复使用」。弃用表灰色虚线显示，**引用它的连线同步转灰虚线**，引用步骤进入"待配置"。
- **无选中**：操作提示。
- **连线说明**：详情面板按当前连线逐条说明"读取哪些表 / 产出哪张新表 / 哪里输入缺失"（承接原画布图例的解释职能，2026-09-17）。

## 动态状态语义

| 视觉 | 含义 |
|------|------|
| 橙描边 + 「待配置」角标 | 步骤参数/输入不完整（输入强制完整校验，不静默） |
| 红虚线短桩 + ⚠ + 「输入缺失」角标 | 步骤引用了不存在的表（悬空，显式提示） |
| 灰填充 + 虚线 + 「已弃用」角标 | 用户显式弃用的表（仍显示；正式版语义=执行跳过+释放内存） |

## 连线（边）类型语义（2026-09-17，画布无图例）

| 连线 | 视觉 | 含义 |
|------|------|------|
| 数据引用边 | 灰（输入表列）/蓝（派生表列）实线，末端箭头 | 步骤使用某张表（自上而下汇入卡片） |
| 数据产出边 | **绿色实线向上** + 标签「新表」/「复制新表」 | 步骤产出一张新操作表（自卡片向上指向顶部表头）；「数据表复制」= 复制出一条新分支 |
| 起止连接边 | 绿/红短实线 + 箭头 | 「▶ 开始」→首步；末步→「■ 结束」 |
| 悬空标记边 | 红虚线短桩 + ⚠ | 下游输入缺失（绝不静默） |
| 弃用引用边 | 灰 `#757575` 虚线 | 引用了已弃用的表（表节点另有「已弃用」角标） |

区分要点：方向（引用向下/产出向上）× 颜色 × 线型（实/虚）× 标签/伴随符号，任两类至少两维不同；点任一节点可在右侧详情读到人话说明。

## W-03 改造项在哪里看

1. **端口不显示**——画布不画任何端口圆点（无开关）
2. **步骤卡片业务化**——卡片带序号徽章 ①②…、操作中文名、一句话业务说明
3. **顶部进度**——流程名 + "已完成 N/M" + 四色迷你进度条
4. **表节点术语化**——"输入表"/"结果表"角标 + 结果表下方"由「某步骤」生成"（输入表与结果表头部错位排布示区分）
5. **开始/结束标记**——首步上方"▶ 开始"+绿色短连线、末步（导出步骤）下方"■ 结束"+红色短连线；增删步骤后自动跟随（结束步被删时落到新末步）
6. **失败人话原因**——红色卡片下方气泡："电费表缺少『客户编号』列，无法完成匹配"
