## §0 Agent 使用本台账规程

**定位**：本台账是 Agent 的**未决问题总账与执行清单**——由 Agent 自行读取、判定、执行、回写，不需要等待逐条填表。

### 0.1 加载义务（命中任一场景，先读本台账再动手）

1. 数据导入相关的任何改动（文件读取／sheet 解析／表头／值处理／类型映射／写库／导入复现）；
2. 功能函数增删改（**同时必须加载** `docs/function-spec-rules.md`）；
3. 依赖、打包、构建、交付身份相关改动；
4. 文档口径回写（`docs/`、`README.md`、实例文档）；
5. 新会话建立上下文时（作为未决问题总账，先于任何代码改动读取）。

### 0.2 列语义与写权限（全部列由 Agent 维护）

| 列 | 语义 | Agent 写权限 |
|----|------|--------------|
| 编号 | 唯一标识 | **只读**：永不复用、永不重排；发现新问题才分配新号 |
| 问题（人话） | 现象描述 | **只读**：除非证据推翻，推翻须在 §10 留痕 |
| 严重度／优先／类型 | P0-P3 或高中低 | **只读**：调整须在 §10 写明依据 |
| 证据 | 文件＋行号／探针实测输出 | 修复后**追加**验证方式，不得删改原文 |
| 状态 | `未修复`／`修复中`／`已修复（日期/轮次）`／`已关闭（理由）`／`待答复` | **必须实时回写**，不得批量补记。枚举值后可附括号说明（如 `未修复（静态路径推定）`、`待答复（红线定性复核）`） |
| 裁定 | `认可`／`不成立（理由）`／`降级为 Pn`／`合并到 XX-nn` | Agent 填写，须附依据 |
| 处置指令 | `本轮修`／`下轮修`／`不修（理由）`／`待补信息（要什么）` | Agent 填写；**人工另有指令时以人工指令为准** |

### 0.5 回写规范（每修完一条，七步齐做）

1. 「状态」列改 `已修复（2026-09-XX/Rn）`；
2. 「证据」列追加验证方式（用例名／smoke 场景／探针输出）；

6. **该条目所属问题组（Q）全部条目修完 → 在 §1.2 该行「严重度」列后追加 `已闭合（日期）`**；
7. **该根本问题（RC）下全部 Q 闭合 → 在 §1.1 该行追加 `已闭合（日期）`**；最后 §10 变更记录追加一行。
