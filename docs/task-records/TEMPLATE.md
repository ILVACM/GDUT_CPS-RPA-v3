# 任务记录结构模板

> **本文件是模板，不是任务记录**，由 [docs/anchor-mechanism.md](../anchor-mechanism.md)（规定层）引用；模板本体独立演进，规定层仅保留指引。
> 新建任务记录时复制以下结构，占位符按实际填写；命名规则 `<YYYY-MM-DD>-<task-slug>.md`。

---

- **开始时间**：
- **最后更新**：
- **要点摘要**：<与锚点层一致>
- **操作人**：黄泊凯

---

## 使用说明

- **逐步追加**：每完成一个关键节点即追加对应记录，禁止一次性写入全部
- **禁止编造**：只记录实际发生的事情，未执行的不写
- **先有后写**：操作完成 → 记录写入，不可先写记录再执行
- **中断标记**：中断步骤标 ⏸️ 并注明原因；续接时追加"续接"标记与时间
- **编码类任务**：须按 AGENTS.md 补充「验收」节记录回归结果（如该类规约条款生效后）
