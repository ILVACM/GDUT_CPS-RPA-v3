# User Manual — RPA 数据处理工具用户手册

> 本手册面向**无技术背景的使用者**。全文使用界面业务语言，不含技术术语；截图占位由人工补充。

## 1. 这个程序帮你做什么

把你每天重复的数据整理工作自动化：从 Excel 文件里取出数据，按你搭好的处理环节（筛选、去重、统计、跨表匹配等）自动加工，最后把结果导出成新的 Excel 文件。

- 不用写公式、不用写代码
- 每一步做什么、先做哪步，都由你在界面上点选决定
- 处理过程可随时终止，结果有清单可查

## 2. 四步上手

### 第一步：选择数据

1. 点 **[add]**（即"添加文件"按钮；按钮文字沿用历史英文 `[add]`，未登记为待办），选中要处理的 Excel 文件（可一次选多个）
2. 选中的数据会出现在下方列表里，共 6 列：**选择、标识名称、来源文件、源数据表、表头行、删除**
   - 勾选本次要用的数据
   - 给它起个「标识名称」——之后配置处理环节时就用这个名字来称呼它
   - 核对「表头行」：标题（列名）在文件的第几行
3. 点 **[确认并导入]**，程序把数据读进来

（截图占位：第一步界面，人工补）

### 第二步：搭处理流程

- 界面左侧是**流程图**（展示处理环节的先后顺序和数据流向），右侧是**参数填写区**
- 点「添加功能步骤 ▾」按钮，加入需要的处理：筛选、去重、条件统计、跨表匹配、导出结果等（共 9 类常用处理）
- 点选某个环节，右侧参数区就地填写条件——条件和列都从下拉菜单里选，不用手打
- 常用的环节组合可存为**模板**（底部模板区），下次一键载入
- 程序会在你改动后约 2 秒自动保存现场：即使中途断电、死机，下次打开也能恢复

（截图占位：第二步界面，人工补）

### 第三步：运行

- 点 **[开始执行]**，界面逐环节显示：等待中 → 执行中 → 已完成/失败（进度列表只显示名称与颜色）
- 中途想停：
  - **[终止操作]**：请求停止，步骤间/导出批次边界生效
  - **[放弃执行]**：请求停止并返回第一步，未完成结果作废

（截图占位：第三步界面，人工补）

### 第四步：看结果

- 结果页显示本次执行的总体情况与导出文件清单
- 若有环节没做完，会如实标注「部分完成」并列出每个环节的完成情况
- 失败原因用日常语言显示；点 **「技术详情」** 可展开原始信息，供管理员排查
- 底栏：**[确定]**（关闭）／**[新一轮操作]**（回到第一步重新开始）／**[保存本次配置]**（把这套环节安排存成模板）

（截图占位：第四步界面，人工补）

## 3. 常见错误自救表

> 与程序内置错误话术同源（`rpa_engine/gui/error_messages.py` 规则表，R6/B1）；界面提示若有更新，以界面为准。

| 看到什么 | 怎么办 |
|----------|--------|
| 步骤用到的数据列不存在。 | 请检查该列是否被改名或删除，修正后重试。 |
| 步骤用到的数据表不存在。 | 请检查该表是否已被删除或弃用，修正后重试。 |
| 文件正被其他程序占用（例如 Excel 未关闭）。 | 请关闭占用该文件的程序后重试。 |
| 找不到指定的文件。 | 请确认文件没有被移动、改名或删除。 |
| 数据量超出了可用内存。 | 请缩小数据范围或分批处理后重试。 |
| 磁盘读写发生错误。 | 请检查磁盘空间是否充足，然后重试。 |
| 数据正忙，本次操作没有完成。 | 请等待几秒后重试；反复出现请报告管理员。 |
| 本次操作已按您的要求终止。 | 如需继续，请重新开始执行。 |
| 本步骤处理时间超出上限。 | 请缩小数据范围后重试，或联系管理员调整上限。 |
| 该文件由更新版本的程序生成。 | 请升级程序后再打开此文件。 |
| 程序遇到意外问题，本次操作未完成。 | 请把日志文件发给管理员查看（日志位置见第 5 章）。 |

## 4. 注意事项

1. **导出会替换同名文件**：导出位置若已有同名文件，会被本次结果直接替换。导出前请确认存放位置，重要文件先另存备份
2. **导入前先关闭 Excel**：文件被 Excel 打开时处于占用状态，会导致导入失败
3. **不要同时打开两个程序窗口**：两个窗口会互相覆盖运行配置；程序检测到后会提示「请关闭另一个窗口后重试」
4. **磁盘空间**：确认导入前程序会自动检查空间是否足够（约需源文件总大小的 3 倍），不足时会提示并停止，请清理磁盘后重试
5. **大数据量处理较慢**：单个环节超过 10 分钟时程序会在日志中提醒（不会中断执行）；界面卡顿时请耐心等待，勿强关程序
6. **换文件后检查环节参数**：重新选择数据后，若某个数据的来源或表头行发生了变化，程序会弹窗列出受影响的环节，请逐个检查参数是否仍然正确

## 5. 找谁求助

- 自救表解决不了时，请联系管理员，并提供三样东西：
  1. 你当时在做什么操作
  2. 界面上显示的提示原文
  3. 大概的发生时间
- **日志文件位置**：程序所在文件夹内的 `logs` 文件夹（例如 `D:\RPA 工具\logs`），把出问题当天的日志文件发给管理员即可
